
# Retinal Blood Vessel Segmentation

Comparison of classical image processing, U-Net,
and hybrid approaches for retinal blood vessel segmentation.

## Project Objective

The aim of this project is to automatically segment
retinal blood vessels from fundus images, with
particular attention to thin vessel detection.

## Dataset

FIVES - Fundus Image Vessel Segmentation Dataset

## Methods

1. Image preprocessing
2. Vessel enhancement (CLAHE, Frangi, Gabor)
3. Classical image segmentation
4. U-Net deep learning
5. Hybrid segmentation
6. Performance evaluation
